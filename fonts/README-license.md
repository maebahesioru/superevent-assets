# フォントのライセンス

## GenShinGothic-P-Regular.ttf（源真ゴシックP Regular）
- 配布元: 自家製フォント工房 https://jikasei.me/font/genshin/
- ライセンス: SIL Open Font License 1.1（本文は同ディレクトリの `OFL-1.1.txt`）
- 再配布可。改変版を配る場合は名前から "Gen Shin Gothic" を外す（Reserved Font Name）。

## 03スマートフォントUI.otf（スマートフォントUI）
- 配布元: フロップデザイン https://www.flopdesign.com/ ／ https://ffont.jp/smartfontui/
- 無料・商用利用可の自由フォント。再配布するときはフロップデザインのクレジットを添える。
